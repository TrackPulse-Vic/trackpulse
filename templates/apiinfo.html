Read Logs

GET /api/<key>/logs

URL parameters:

  • mode (optional): Filter logs by mode (e.g., victrain, nswbus, etc.)

Response example:

    {
        "date": "2025-11-02",
        "end": "Lilydale",
        "id": 4671,
        "line": "Lilydale",
        "mode": "victrain",
        "notes": "",
        "number": "1M-1301T-2M",
        "operator": "Metro Trains Melbourne",
        "start": "Croydon",
        "tags": null,
        "type": "X'Trapolis 100"
    }

GET /api/<key>/logs.csv

URL parameters:

  • mode (optional): Filter logs by mode (e.g., victrain, nswbus, etc.)

Response example:

        id,mode,date,operator,number,type,line,start,end,notes,tags
        4671,victrain,2025-11-02,Metro Trains Melbourne,1M-1301T-2M,X'Trapolis 100,Lilydale,Croydon,Lilydale,"","None"
